Lantern Lane — an original spot-the-difference game: three hand-drawn canvas scenes (a night market, a firefly garden, harbour lights), 7/8/10 hidden differences, hints, a timer and combo scoring. Find every difference between the two panels before time runs out.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 and play with mouse and keyboard.
